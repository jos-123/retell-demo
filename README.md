# Retell AI Demo

## Prerequisites

- Node.js installed
- Retell AI API credentials (optional for some features)

## Installation

```bash
npm install
```

## Running the Project

```bash
npm start
```

or

```bash
node server.js
```

The server will start at [http://localhost:3000](http://localhost:3000).

## Configuration

Some features require Retell AI API keys. Update `server.js` with your specific keys if needed.
